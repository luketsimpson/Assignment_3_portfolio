Projects

Project 1: Student Internship Network

A RateMyProfessor-style web app where students post honest reviews of internships they completed, so future applicants know what a role is really like before applying. Built as a Scrum team project for CS 1530 (Software Engineering), using Java, Spring Boot, Thymeleaf, HTML/CSS/JavaScript, and PostgreSQL. I learned how to turn a rough idea into prioritized requirements, model the domain with UML before coding, and balance what users want against that the team can deliver in each sprint.

Project 2: Donor Clustering Model

A Python model that groups potential university donors by giving history, gift purpose, academic background, and demographics, then gives each donor a percentage likelihood of interest in each of the university's impact areas, such as entrepreneurship, sustainability, and medical research. Built with pandas and scikit-learn Gaussian Mixture Models. I learned that features matter more than the algorithm: my early clusters split mostly by age and wealth, so I rebuilt the features around gift purpose and degree, weighted recent gifts more heavily, and kept the logic simple enough to explain to non-technical stakeholders.
